Sync collections with Android or another Windows device

Transfer a single Arcane Vault collection snapshot (JSON) between installations. It includes Arena ownership, physical printings and preferred artwork, without needing to reimport the original CSV. Use Wi-Fi QR, USB debugging QR, or transfer a JSON sync file via a normal USB file connection. No cloud account or automatic background synchronization.

USB QR requires USB debugging enabled, a trusted computer approval on your Galaxy, and Android SDK Platform-Tools (ADB) installed on Windows. The ordinary USB cable/file-transfer fallback is Export collection sync file → copy JSON to Galaxy → Import sync file in Android. Import replaces the selected collection, never adds quantities. A local rollback snapshot is saved before import. Arena match log monitoring can update Arena ownership later.

Scan with Arcane Vault Android → Physical Collection → Scan Windows QR. Wi-Fi mode requires the same LAN; USB mode requires a USB debugging connection. Links expire in 5 minutes or after one download. No cloud storage.

Physical copies are tracked separately from Arena ownership, wildcards, and automatic Arena log updates. This is a local inventory, not an Arena collection sync. Imported card versions are preserved by set code and collector number when available.

How to search

Use the role chips for Ramp, Removal, Discard, Stax, Lifegain, Tutors, Haste, Protection, and other deckbuilding functions. These are assigned from official Oracle text using broad heuristics, so they're powerful browsing aids but not definitive rules judgments. Search also matches the full Oracle text after enrichment. Filtering on rarity, mana value, color identity, or types works best once card data is synced.

For split cards, double-faced cards, and specialized digital-only Arena variants, the name matching may occasionally select the wrong printing or miss a card. Check the displayed card face, set, and Scryfall link before crafting. Card ratings are not claimed.
