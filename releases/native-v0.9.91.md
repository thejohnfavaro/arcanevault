# Arcane Vault Native Windows v0.9.91 — Shortlist star alignment

## Added
- A dedicated optical centering template for shortlist star overlays on card art.

## Changed
- The starred/unstarred icon uses consistent Segoe UI Symbol metrics and an explicit square centering container, with a small optical vertical adjustment.

## Fixed
- Shortlist star glyph is no longer visually offset within its square overlay in the Card Catalog art view.

## Removed
- Reliance on default button text baseline alignment for the shortlist overlay glyph.

## Safety
- Shortlist toggle actions, selection state, storage, collection value and card image behavior are unchanged.
- v0.9.90 responsive EDH layout behavior is preserved.
