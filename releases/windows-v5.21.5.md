# Arcane Vault for Windows v5.21.5

## Added
- Set Progress sorting by set release date, newest-first or oldest-first, using local Scryfall printing dates.
- Release dates displayed on Set Progress tiles; sorting preferences are remembered.

## Changed
- Unknown set release dates sort after dated sets in both chronological directions.
- LAN/USB QR transfer links remain retryable until expiry if a connection fails before the full response is sent.

## Fixed
- Interrupted collection transfers no longer immediately invalidate an otherwise valid transfer token when sending fails.

## Removed
- No existing user-facing features removed.
