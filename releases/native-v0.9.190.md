# Arcane Vault Native Windows v0.9.190 (Preview)

## Added
- Uniform 470×167 desktop deck-library tiles so all saved decks have matching dimensions regardless of name, favorite badge, review, bracket or other metadata.
- Arena Brawl decks may select any official Scryfall printing for purely cosmetic deck artwork, including double-faced commanders.

## Changed
- Commander card preview and saved deck cover honor an explicit cosmetic printing even when the deck format is Arena Brawl.
- Printing selector labels distinguish deck presentation choices from actual owned MTG Arena styles.

## Fixed
- Deck-library cards no longer vary in width based on the amount of displayed metadata.
- Earlier Arena Brawl printing restriction no longer leaves commander artwork selection limited to a representative preview.

## Removed
- Nothing. All printings remain separate from verified owned inventory, and editing artwork does not change the deck list.

## Verification
- Open the Deck Library and compare saved deck tile sizes across decks with and without review/bracket/favorite labels.
- Select the commander row in an Arena Brawl deck, pick an official Scryfall printing and save the deck.
- Reopen the deck and confirm the card preview and deck-cover image honor the choice without changing ownership.
